**在线地址：https://chenzhangsheng55-stack.github.io/shengli/**

### 主观题怎么判分

名词解释、简答、案例分析每题拆成若干**得分点**（每点 1 分），交卷时按关键词自动判断答到了哪些点；部分题"答出任意 N 点即满分"。自动判分只是参考，成绩页每个得分点都能点一下改判（✓/✗），本题分、总分、最近成绩和错题统计会同步更新。主观题得分不到满分的 60% 记为错题。

## 错题统计（按章 / 单元）

- 每次交卷，作答过的题记一次"做过"，答错再记一次"做错"；未作答的不计入。
- 首页「薄弱模块 · 累计错误率」：按 12 章分组列出 31 个单元的累计错误率，顶部标出错误率最高的 3 个单元（至少做过 3 题才参与排名）。
- 成绩页「本卷各单元错题」：这一套里每个单元错了几道。
- 「错题本」：所有做错过的题按累计做错次数从多到少排列，可按章筛选，附答案、解析或得分点。
- 统计存在本机浏览器 `localStorage`（键名前缀 `sl_`），换设备不同步；「清空统计」只清错题统计。

## 限时与防作弊

- 全卷限时 **120 分钟**，剩 5 分钟转红，归零自动交卷。时长改 `site/index.html` 里的 `EXAM_MINUTES`。
- 离开答题界面（切应用、锁屏、切标签页、搜题悬浮窗/分屏抢焦点）即计次，**累计 2 次自动交卷**。
- 题干与选项禁止选中、复制、右键（填空框和主观题作答框不受影响）。
- 截屏 OCR 型悬浮窗不抢焦点、不隐藏页面，网页探测不到，对它起作用的是限时。

## 抽题规则

每种题型各洗成一副牌顺序取题，**走完整副才重洗**：选择 574 道、填空 134 道 → 11 套以上不撞题；名词解释、简答各 76 道 → 15 套不撞题；案例分析 25 道 → 8 套不撞题。选项顺序每次重新打乱。

## 怎么加题

题库按单元组织，每个单元一段 `push({c:章, u:单元, items:[...]})`。

选择题，**正确答案写在第一个**，组卷时自动打乱：

```js
["题干", ["正确答案","干扰项","干扰项","干扰项","干扰项"], "解析"],
```

填空题，`____`（四个下划线）为空位，每题最多 2 个空，同一空的多种写法都列进去：

```js
["神经调节的基本方式是____，其结构基础是____。", [["反射"],["反射弧"]]],
```

主观题，`t` 为 名词/简答/案例，`p` 是得分点：`[说明, 关键词组...]`，组内用 `|` 分隔同义写法，所有组都出现才算答到这一点；`re:` 开头按正则匹配。CI 会检查参考答案 `r` 能否命中每个得分点：

```js
{t:"名词", q:"脉压", r:"收缩压与舒张压的差值。", p:[["收缩压","收缩压"],["与舒张压之差","舒张压"]]},
```

改了题干会被当成新题重新统计。

## 部署

推送到 `main` 即自动部署（`.github/workflows/deploy.yml`）：先跑 `node scripts/check_bank.js`（选项、空位数、标准答案能否被判对、主观题参考答案能否命中全部得分点），通过后发布 `site/`；不通过则不发布，线上保持上一个可用版本。
